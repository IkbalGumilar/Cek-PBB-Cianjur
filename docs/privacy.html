Kebijakan Privasi (Privacy Policy)

Terakhir Diperbarui: 24 Oktober 2026 • Berlaku Efektif: 24 Oktober 2026

Selamat datang di Cek PBB Cianjur. Dokumen Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan aplikasi Cek PBB Cianjur di platform Android dan Desktop.

Kami berkomitmen penuh untuk menjaga transparansi dan melindungi privasi seluruh pengguna dan wajib pajak. Aplikasi ini dirancang dengan arsitektur offline-first, di mana seluruh data operasional disimpan langsung di perangkat pengguna secara lokal.

1. Informasi yang Kami Kumpulkan

A. Data Pajak & Catatan Kolektor (Disimpan Secara Lokal)

Aplikasi memproses data Nomor Objek Pajak (NOP), nama wajib pajak, alamat objek pajak, ketetapan tagihan, serta status pembayaran (lunas / titip bayar) yang bersumber dari berkas Daftar Himpunan Ketetapan Pajak (DHKP) resmi atau layanan portal publik PBB Bapenda Cianjur. Seluruh data ini tersimpan di penyimpanan internal perangkat Anda dalam basis data terenkripsi lokal dan tidak pernah dikirim ke server pihak ketiga manapun.

B. Informasi Akun Google (Otentikasi Pengguna)

Jika Anda secara sukarela memilih untuk menautkan akun Google Anda melalui menu Pengaturan (untuk tujuan sinkronisasi cadangan DHKP), aplikasi menerima informasi profil dasar dari Google Identity Services:

  • Alamat email Google Anda
  • Nama tampilan profil (Display Name)
  • URL foto profil pengguna

Informasi ini hanya digunakan untuk menampilkan identitas akun yang aktif di aplikasi dan memvalidasi kepemilikan cadangan data.

2. Penggunaan Izin Google Drive (Prinsip Least-Privilege)

Aplikasi Cek PBB Cianjur meminta izin akses terbatas ke Google Drive untuk fitur pencadangan otomatis (cloud backup) dan pemulihan data (restore).

Prinsip Akses Minimum (Least-Privilege):
Aplikasi HANYA meminta izin https://www.googleapis.com/auth/drive.file dan https://www.googleapis.com/auth/drive.appdata. Aplikasi DILARANG KERAS dan TIDAK MEMILIKI KEMAMPUAN TEKNIS untuk melihat, membaca, mengunduh, mengedit, atau menghapus berkas pribadi Anda lainnya di Google Drive.

Secara spesifik, aplikasi hanya berinteraksi dengan:

  • Folder khusus bernama Cek PBB Cianjur yang dibuat di Google Drive Anda.
  • Berkas cadangan basis data DHKP (ekstensi .dkhp atau .zip) yang dihasilkan oleh aplikasi ini sendiri.

3. Kepatuhan Kebijakan Data Pengguna Google API Services

Penggunaan dan transfer informasi yang diterima dari Google APIs oleh Cek PBB Cianjur ke aplikasi lain akan selalu mematuhi Kebijakan Data Pengguna Layanan API Google (Google API Services User Data Policy), termasuk persyaratan Penggunaan Terbatas (Limited Use requirements):

  • Kami TIDAK PERNAH menjual, menyewakan, atau memperdagangkan data pengguna atau data akun Google kepada pihak ketiga.
  • Kami TIDAK MENGGUNAKAN data Google Drive untuk periklanan, penargetan iklan (ads), analisis pihak ketiga, atau penilaian kredit.
  • Data hanya digunakan semata-mata untuk fungsi pencadangan dan pemulihan data DHKP atas permintaan pengguna.
  • Tidak ada manusia (pengembang atau staf) yang membaca isi berkas cadangan Anda di Google Drive; seluruh proses transfer data dilakukan secara otomatis terenkripsi mesin.

4. Keamanan Informasi & Enkripsi

Kami menerapkan standar keamanan informasi tingkat tinggi untuk melindungi data Anda:

  • Enkripsi Berkas DHKP: Berkas cadangan yang diunggah ke Google Drive dienkripsi menggunakan algoritma standar industri AES-256 (CBC/GCM) dengan derivasi kunci aman PBKDF2-HMAC-SHA256 (minimal 100.000 hingga 600.000 iterasi).
  • Penyimpanan Kredensial Aman: Token otorisasi Google OAuth disimpan dalam penyimpanan aman tingkat sistem operasi (Android Keystore / Secure Storage).
  • Kunci Aplikasi: Aplikasi dilengkapi fitur kunci biometrik (Fingerprint / Face Recognition) untuk mencegah akses tidak berwenang ke aplikasi di perangkat fisik.

5. Kontrol Pengguna & Penghapusan Data

Anda memiliki kendali penuh atas data Anda kapan saja:

  • Memutus Tautan Akun Google: Anda dapat melepas tautan akun Google kapan saja melalui menu Pengaturan → Cadangan Data DHKP → Lepas Akun Google. Token sesi akan langsung dihapus dari perangkat.
  • Menghapus Akses via Google: Anda dapat mencabut izin aplikasi kapan saja melalui halaman resmi Google Account Permissions.
  • Menghapus Berkas Cadangan: Anda dapat menghapus berkas cadangan langsung dari folder Cek PBB Cianjur di Google Drive Anda atau dari menu kelola cadangan di aplikasi.

6. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu untuk mencerminkan pembaruan fitur atau ketentuan hukum yang berlaku. Versi terbaru akan selalu dipublikasikan pada halaman ini dengan tanggal pembaruan yang diperbarui.
