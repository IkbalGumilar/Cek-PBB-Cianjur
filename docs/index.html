Manajemen & Cek Tagihan PBB-P2 Kabupaten Cianjur

Solusi cerdas bagi kolektor desa dan masyarakat untuk pengecekan tagihan NOP, pencatatan blok DHKP secara offline, rekap penagihan cepat, dan pencadangan data otomatis.

Unduh Aplikasi Baca Kebijakan Privasi

Fitur Unggulan

Didesain untuk kecepatan kerja di lapangan, baik saat ada sinyal maupun di pelosok offline.

🔍

Cek NOP Real-Time & Cepat

Integrasi langsung dengan basis data PBB Kabupaten Cianjur. Dilengkapi pemindai kamera (OCR) dan riwayat pencarian cepat.

📁

Manajemen DHKP & Blok Desa

Impor basis data DHKP desa, kelola blok penagihan per kolektor, dan tandai status lunas atau titip bayar secara offline.

☁️

Pencadangan Google Drive

Cadangkan data DHKP secara berkala ke folder Google Drive pribadi pengguna untuk menjamin data tidak hilang saat ganti perangkat.

🖨️

Cetak Struk Bluetooth & PDF

Cetak bukti tanda terima sementara (STTS) langsung ke printer thermal Bluetooth kolektor atau simpan sebagai dokumen PDF.

🔒

Kunci Aplikasi Biometrik

Lindungi kerahasiaan data wajib pajak dengan proteksi Sidik Jari, Face Unlock, atau PIN kunci layar perangkat.

🛡️

Enkripsi AES-256 Kuat

Paket berkas .dkhp dilindungi algoritma enkripsi AES-256-CBC/GCM dengan PBKDF2 600.000 iterasi.

Komitmen Keamanan & Privasi Data

Cek PBB Cianjur menghormati privasi penuh pengguna dan wajib pajak. Kami menerapkan prinsip Least Privilege dalam integrasi Google Drive.

  • Aplikasi hanya mengakses berkas miliknya sendiri di folder Cek PBB Cianjur
  • Aplikasi tidak pernah membaca atau mengintip berkas pribadi pengguna di Google Drive
  • Data disimpan secara lokal di perangkat tanpa perantara server komersial pihak ketiga
  • Patuh terhadap Kebijakan Data Pengguna Layanan API Google

Integrasi Terpercaya

Fitur sinkronisasi cloud dirancang transparan dengan izin terbatas (drive.file) agar pengguna memiliki kendali penuh atas datanya.
